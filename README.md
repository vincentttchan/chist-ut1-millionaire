# 中史 UT1 百萬富翁

中一及中二中國歷史溫習遊戲，各45題，每局30題，設三種求助及逐題作答回顧。

- 學生入口：https://vincentttchan.github.io/chist-ut1-millionaire/
- GitHub Pages 提供遊戲畫面，Google Apps Script 核對答案並讀寫私人 Google Sheets 排行榜。
- 中一、中二分榜；以答對題數排序，同分比較伺服器用時。
- 只須遊戲暱稱，不需學生姓名、班別或學號。線上版預設參加排行，輸入暱稱即可開始；可取消勾選以只作練習。
- 同一瀏覽器每級保留最佳紀錄；此為練習榜，未核實學生身分。

## 部署

GitHub Pages 從 `main` 分支根目錄發布，不需要建置。`index.html` 含所需樣式及題庫，直接下載亦可離線練習。

`apps-script/` 是排行榜後端原始碼備份。更新後端時須在 Apps Script 項目內同步對應檔案，並更新**現有部署**的版本，才能保留網址。試算表ID及玩家雜湊用的鹽值只存於 Apps Script 的指令碼屬性，不放在此儲存庫。

跨來源連線使用具有來源、隨機連線識別碼及訊息來源核對的 postMessage 通道。只有指定 GitHub Pages 來源可使用通道，並且只允許開始局次、提交局次及讀取排行榜三種操作。分數與用時由伺服器計算，重複提交可安全重試。

GitHub Pages 來源不同於原 Apps Script 網頁，瀏覽器會為新網站建立新的隨機玩家識別碼；原排行榜資料仍保留。

題目以用戶提供的中一、中二溫習筆記為範圍，加入基礎、理解及應用分析題。情境題為教學編寫，並非歷史原始史料引文。排行榜用時受連線及題目隨機抽樣影響，適合作溫習激勵。
